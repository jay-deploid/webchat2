Embedded Messaging — Standalone Test Page

This is a plain HTML page (no Visualforce) used to test whether the Salesforce Embedded Messaging chat widget loads and connects correctly outside the Salesforce domain/CSP context.

If the widget appears in the bottom corner but still won't connect from Singapore, open the browser console (F12) and check the Network/Console tabs for errors — that will confirm whether it's a network/firewall block vs. a Salesforce-side config issue.
